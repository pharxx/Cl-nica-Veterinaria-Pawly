Diagrama E-R

Esta sección presenta el modelo entidad-relación de la base de datos desarrollada para el sistema de gestión veterinaria. En ella se representan las entidades principales del sistema, sus atributos y las relaciones existentes entre cada una, permitiendo visualizar de manera estructurada cómo se organiza y conecta la información dentro de la base de datos.

Entidad Atributos Rol
Propietario ID, Nombre, apellido, teléfono, correo y dirección Representa a las personas que llevan mascotas a la veterinaria.
Mascota ID, nombre, especie, raza, edad y propietario Es la entidad principal del sistema, porque casi todo gira alrededor de la mascota.
Veterinario ID, nombre, apellido, especialidad. Representa al personal médico.
Citas ID, fecha, estado, motivo y precio Controla las consultas programadas o realizadas.
Tratamiento ID, nombre, descripción, duración, fecha de inicio y fin, estado y costo Controlar tratamientos médicos.

Consultas y Scripts SQL

1. Registros de la entidad principal ordenados alfabéticamente 

            
SELECT * FROM mascotas
ORDER BY nombre_mascota ASC;

Resultados de la consulta:

id_mascota nombre_mascota especie raza edad id_propietario

2. Registro específico filtrando por un campo de texto y cláusula WHERE

            
SELECT * FROM propietarios 
WHERE nombre_propietario LIKE '%Norma%';

Resultados de la consulta:

3. Registro que cumpla una condición numérica

            
SELECT id_antibiotico, nombre_antibiotico, stock_antibiotico
FROM antibioticos

4.Mascotas agrupadas por especie 

            
SELECT especie, COUNT(*) AS total_por_especie
FROM mascotas 
GROUP BY especie;

Perro 23

5.Citas programadas para una fecha 

            
SELECT id_mascota, id_propietario, fecha_cita, estado_cita 
FROM citas
WHERE fecha_cita BETWEEN '2026-04-01' AND '2026-04-30';

Resultados de la consulta:

id_mascota id_propietario fecha_cita estado_cita
32 32 2026-04-01 Confirmada

6.Propietarios con más de una mascota agregada 

            
Select id_propietario, COUNT(*) AS total_mascotas
FROM mascotas 
GROUP BY id_propietario;

Resultados de la consulta:

id_propietario total_mascotas
20 3

7.Cita con nombre de la mascota, propietario y veterinario 

            
SELECT 
    citas.id_cita,
    mascotas.nombre_mascota AS mascota,
    propietarios.nombre_propietario AS propietario,
    veterinarios.nombre_veterinario AS veterinario,
    citas.fecha_cita
FROM citas
INNER JOIN mascotas 
    ON citas.id_mascota = mascotas.id_mascota
INNER JOIN propietarios 
    ON mascotas.id_propietario = propietarios.id_propietario
INNER JOIN veterinarios 
    ON citas.id_veterinario = veterinarios.id_veterinario;

Resultados de la consulta:

id_cita mascota propietario veterinario fecha_cita
1 Rufo Geraldine Ana 2026-03-01

8. Tratamientos aplicados a cada mascota con su fecha 

            
SELECT
    mascotas.nombre_mascota AS mascota,
    tratamiento.descripcion_tratamiento,
    tratamiento.fecha_inicio,
    tratamiento.fecha_fin
FROM tratamiento
INNER JOIN mascotas
    ON tratamiento.id_mascota = mascotas.id_mascota;

Resultados de la consulta:

mascota descripcion_tratamiento fecha_inicio fecha_fin
Rufo Control de infección respiratoria 2026-01-02 00:00:00 2026-01-09 00:00:00

9. Reporte de actividad de cada veterinario 

            
SELECT
    veterinarios.nombre_veterinario AS veterinario,
    COUNT(DISTINCT citas.id_cita) AS citas_atendidas,
    COUNT(DISTINCT tratamiento.id_tratamiento) AS tratamientos_aplicados,
    COUNT(DISTINCT citas.id_mascota) AS mascotas_distintas
FROM veterinarios
LEFT JOIN citas
    ON veterinarios.id_veterinario = citas.id_veterinario
LEFT JOIN tratamiento
    ON veterinarios.id_veterinario = tratamiento.id_veterinario
GROUP BY veterinarios.nombre_veterinario;

Resultados de la consulta:

veterinario citas_atendidas tratamientos_aplicados mascotas_distintas

A continuación se muestra una simulación del proceso de registro de citas desarrollado
en Pseudocódigo y su Diagrama de Flujo:

Algoritmo RegistroCitasVeterinaria
// 1. Definición de variables
    Definir opcion_menu, edad, id_sala Como Entero;
    Definir nombre_mascota, especie, raza, nombre_prop, apellido_prop Como Cadena;
    Definir telefono_prop, correo_prop, direccion_prop, nombre_vet, fecha_cita Como Cadena;
    Definir costo_base, costo_total, descuento Como Real;
    Definir es_nueva Como Logico;
// Definimos un costo base imaginario para la consulta
costo_base <- 200.00;
Repetir
// 1. Menú de mascota
    Escribir '=== MENÚ PRINCIPAL ===';
    Escribir '1. Registrar Mascota Nueva';
    Escribir '2. Mascota ya registrada';
    Escribir '3. Salir del sistema';
    Escribir 'Seleccione una opción: ';
Leer opcion_menu;
Si (opcion_menu = 1) O (opcion_menu = 2) Entonces
// 1.1 Opción Mascota Nueva
  Si opcion_menu=1 Entonces
    es_nueva <- Verdadero;
    Escribir '--- Registro de Mascota Nueva ---';
    Escribir 'Ingrese nombre de la mascota: ';
    Leer nombre_mascota;
    Escribir 'Ingrese especie (perro, gato, etc.): ';
    Leer especie;
    Escribir 'Ingrese raza: ';
    Leer raza;
    Escribir 'Ingrese edad: ';
    Leer edad;
    Escribir 'Ingrese nombre del propietario: ';
    Leer nombre_prop;
    Escribir 'Ingrese apellido del propietario: ';
    Leer apellido_prop;
    Escribir 'Ingrese teléfono del propietario: ';
    Leer telefono_prop;
    Escribir 'Ingrese correo (opcional): ';
    Leer correo_prop;
    Escribir 'Ingrese dirección: ';
    Leer direccion_prop;
    // 1.2 Opción Mascota ya Registrada
  SiNo
    es_nueva <- Falso;
    Escribir '--- Mascota Ya Registrada ---';
    Escribir 'Ingrese nombre de la mascota: ';
    Leer nombre_mascota;
    // Se asume que el propietario ya existe en base de datos
    nombre_prop <- 'Cliente Frecuente (Registrado)';
FinSi
// 2. Creación de cita
Escribir '--- Datos de la Cita ---';
Escribir 'Ingrese nombre del veterinario: ';
Leer nombre_vet;
Escribir 'Ingrese fecha de la cita (Ej. 28/05/2026): ';
Leer fecha_cita;
// Ciclo para validar el ID de la sala (1 a 50)
Repetir
    Escribir 'Ingrese ID de la sala de consultorio (1 a 50): ';
    Leer id_sala;
    Si (id_sala< 1) o (id_sala>50) Entonces
    Escribir 'Error: La sala debe estar entre 1 y 50. Intente de nuevo.';
    FinSi
Hasta Que id_sala>=1 Y id_sala<=50
// Cálculo del costo con condicional para el descuento del 10 MOD
Si es_nueva=Verdadero Entonces
    descuento <- costo_base*0.10;
    costo_total <- costo_base-descuento;
    Escribir '¡Se ha aplicado un descuento del 10% por mascota nueva!';
SiNo
    costo_total <- costo_base;
FinSi
// 3. Confirmación de cita
Escribir '===================================';
Escribir '       CONFIRMACIÓN DE CITA        ';
Escribir '===================================';
Escribir 'Nombre mascota: ', nombre_mascota;
Escribir 'Propietario: ', nombre_prop;
Escribir 'Veterinario: ', nombre_vet;
Escribir 'Sala asignada: Consultorio ', id_sala;
Escribir 'Fecha de la cita: ', fecha_cita;
Escribir 'Costo total a pagar: Q', costo_total;
Escribir '===================================';
Escribir ''; // Salto de línea para estética
SiNo
Si opcion_menu<>3 Entonces 
    Escribir 'Opción inválida. Por favor, seleccione 1, 2 o 3.';
FinSi
FinSi
Hasta Que opcion=3
Escribir 'Saliendo del sistema...';
FinAlgoritmo
